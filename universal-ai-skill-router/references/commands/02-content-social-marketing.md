# Content creation, social media & marketing

Category file `2` of the Universal AI Skill Router. **100 commands.** Source: `source/README.original.md`.

**Execution profile (category 2).** Produce ready-to-use content for the platform or format named. Numbers in a command name are literal (`/hook10` = 10 hooks, `/hook50` = 50, `/script30` = a 30-second script, `/caption10` = 10 captions). Ask for platform/audience/tone only if truly missing and the task cannot proceed without it; otherwise state a brief assumption and proceed. Creator/brand names used as styles (`/vox`, `/kurzgesagt`, `/netflix`, `/bbc`, ...) mean the *approach/structure* described, never imitation of copyrighted text or fabricated quotes. Do not invent statistics, claims, or results.

> Each line below is `command — original README definition (verbatim)`. The definition is the command's behavior: do what it says to the user's task. Commands marked ★ also have an explicit longer definition in `references/detailed-definitions-and-examples.md` that MUST be applied.
