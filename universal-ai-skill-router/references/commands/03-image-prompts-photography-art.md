# Image prompts, photography & art direction

Category file `3` of the Universal AI Skill Router. **100 commands.** Source: `source/README.original.md`.

**Execution profile (category 3).** These are image/photo/art-direction commands. Claude does not render photographs by itself: unless an image-generation tool is actually available in the session, the deliverable is a detailed concept plus a copy-ready image-generation prompt (subject, composition, camera/lens or medium, lighting, palette, mood, style, aspect ratio, optional negative prompt). Say plainly that the output is a prompt/concept, not a generated image. If an image tool exists and the user asked for the image itself, use it. Where the command names a camera angle, lighting, film look, era, genre, or medium, apply it as the controlling visual attribute. Combined image commands layer together into ONE coherent prompt. Do not depict real private individuals or copyrighted characters.

> Each line below is `command — original README definition (verbatim)`. The definition is the command's behavior: do what it says to the user's task. Commands marked ★ also have an explicit longer definition in `references/detailed-definitions-and-examples.md` that MUST be applied.
