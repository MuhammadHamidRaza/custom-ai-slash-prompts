# Creative thinking, expert perspectives, AI workflows & advanced prompting

Category file `5` of the Universal AI Skill Router. **100 commands.** Source: `source/README.original.md`.

**Execution profile (category 5).** Perspective/role commands (`/doctor`, `/lawyer`, `/founder`, `/investorview`, `/mentor`, ...) mean: reason from that viewpoint while staying accurate and honest; medical and legal ones are educational, not professional advice. Idea commands with numbers are literal (`/ideas10`, `/ideas50`). `/finalanswer` returns only the answer. `/thinking` gives a high-level summary of the reasoning approach, not a dump of raw internal reasoning. `/confidence`, `/uncertainty`, `/limitations` must be genuinely calibrated. Prompt-engineering commands (`/metaprompt`, `/systemprompt`, `/promptchain`, `/masterprompt`, `/allinone`...) produce reusable, well-structured prompts. Do not invent capabilities.

> Each line below is `command — original README definition (verbatim)`. The definition is the command's behavior: do what it says to the user's task. Commands marked ★ also have an explicit longer definition in `references/detailed-definitions-and-examples.md` that MUST be applied.
