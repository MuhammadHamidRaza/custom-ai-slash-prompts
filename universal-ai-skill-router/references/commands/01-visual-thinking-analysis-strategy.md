# Visual thinking, explanations, analysis & strategy

Category file `1` of the Universal AI Skill Router. **100 commands.** Source: `source/README.original.md`.

**Execution profile (category 1).** Deliver the form the command names. Visual/structural commands (diagram, flowchart, mindmap, timeline, infographic, blueprint, comparison, dashboard, etc.) should be produced in the best rendering the environment offers: Mermaid, SVG, HTML, a markdown table, or ASCII/text layout; if no rendering is available, use a clean, labelled text structure and say what visual it represents. Named frameworks (SWOT, PESTLE, Porter's Five Forces, Five Whys, decision matrix, root cause) must follow the real framework faithfully. Teaching/testing commands (eli5, quiz, flashcards, viva, interview, socratic...) should be interactive or structured as named. Identify missing information instead of guessing.
