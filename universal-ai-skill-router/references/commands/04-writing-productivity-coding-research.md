# Writing, productivity, coding & research

Category file `4` of the Universal AI Skill Router. **101 commands.** Source: `source/README.original.md`.

**Execution profile (category 4).** Apply the command to the text, code, data, or plan the user supplies (or to the most recent relevant content in the conversation). Editing commands preserve meaning unless the command says otherwise (`/rewrite`, `/paraphrase`) and `/grammar` changes grammar only. Format commands (`/json`, `/yaml`, `/csv`, `/xml`, `/sql`, `/regex`) must output valid, copy-ready content in a code block. Code commands deliver correct, explained code and must not invent bugs that the code does not show. Planning commands (`/okr`, `/gantt`, `/roadmap90`, `/risks`...) give concrete, realistic, structured outputs with stated assumptions.

> Each line below is `command — original README definition (verbatim)`. The definition is the command's behavior: do what it says to the user's task. Commands marked ★ also have an explicit longer definition in `references/detailed-definitions-and-examples.md` that MUST be applied.
