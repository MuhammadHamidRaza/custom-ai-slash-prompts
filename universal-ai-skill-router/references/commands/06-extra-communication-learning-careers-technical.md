# Extra shortcuts: communication, learning, careers & technical work

Category file `6` of the Universal AI Skill Router. **61 commands.** Source: `source/README.original.md`.

**Execution profile (category 6).** Many of these are modifiers on tone, audience, language, or verification (`/concise`, `/plainenglish`, `/romanurdu`, `/urdu`, `/translate`, `/currentcheck`, `/citationcheck`...). `/currentcheck` and other freshness/verification commands should use web search when it is available and say so when it is not. Language commands: `/romanurdu` = Urdu written in Latin script; `/urdu` = Urdu script. Career/communication commands (`/coverletter`, `/resume`, `/ats`, `/jobmatch`...) must be truthful to the user's real background: never fabricate experience, employers, or credentials. Technical commands (`/securityreview`, `/threatmodel`, `/database`, `/devops`, `/n8nworkflow`, ...) give actionable, structured output and defensive framing.

> Each line below is `command — original README definition (verbatim)`. The definition is the command's behavior: do what it says to the user's task. Commands marked ★ also have an explicit longer definition in `references/detailed-definitions-and-examples.md` that MUST be applied.
